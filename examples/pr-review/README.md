# Демонстрационные merge request для LLM-анализа

| Кейс | Изменение | Что должен найти анализ | Что нельзя считать покрытым |
|---|---|---|---|
| `destructive-migration` | Статус заказа перенесён в новую таблицу, `orders.status` удалён | Предыдущая версия и откат ломаются; миграция не является expand-only | AC-3: откат после миграции, теста нет |
| `idempotency-key-relaxed` | Ключ от 4 символов; при рефакторинге удалена проверка конфликта | Повтор ключа с другим товаром больше не даёт 409; короткие ключи | AC-1: теста нет; AC-2: оба теста падают |
| `canary-threshold-weakened` | `maxErrorRatio` 0.02 → 0.25, `failureLimit` 1 → 5, p95 400 → 2000 мс | Порог противоречит критерию 2 %; откат запаздывает | AC-1 и AC-2: kind-сценарии в этом pipeline не запускались |

`diff.patch` построен по реальным файлам репозитория и применяется к текущей ревизии (`git apply --check`). `junit.xml` и `lcov.info` — подготовленные входные данные кейса. `guard-fixture.json` — синтетический ответ для проверки guard, а не запись ответа модели.

Запуск и критерии: [docs/llm-review.md](../../docs/llm-review.md).
