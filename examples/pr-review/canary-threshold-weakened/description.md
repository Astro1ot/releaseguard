# Снизить количество ложных откатов canary

На прошлой неделе canary дважды откатывался из-за кратковременных всплесков. Ослабляем пороги анализа: допускаем больше неуспешных измерений и выше задержку.

## Критерии приёмки
- Canary с долей 5xx выше 2% автоматически отклоняется, весь трафик возвращается на stable
- Кратковременный всплеск задержки (одно измерение) не приводит к откату
